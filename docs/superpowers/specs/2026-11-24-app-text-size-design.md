# 앱 전체 글자 크기 설정 — 짧은 설계

## 왜
어르신 대상 서비스인데 글자 크기 설정이 AI 채팅에만 있다. 홈·통화·연락 화면과 보호자 화면은 글자가 고정이라 어르신(과 보호자)이
읽기 어렵다. 문서에도 "큰 글씨 대응 부족"이 한계로 적혀 있다.

## 목표 / 비목표 / 하지 말 것
- 목표: 앱 모든 화면의 글자를 4단계(작게·보통·크게·아주 크게)로 키우고 줄일 수 있다. 어르신·보호자 둘 다. 이 기기에 저장한다.
- 비목표: 화면마다 크기를 따로 정하기, 서버에 저장하기, 아이콘·여백 크기 바꾸기.
- 하지 말 것: 채팅 글자가 두 번 커지는 것(전체 배율 + 채팅 자체 크기), 큰 글씨에서 글자가 잘리거나 버튼이 화면 밖으로 나가는 것.

## 접근 (고른 것)
1. **앱 맨 위에서 글자 배율을 한 번 건다(채택).** `MaterialApp.builder`에서 `MediaQuery.textScaler`를 바꾼다. 화면마다 고정된 글자 크기(수백 곳)를 건드리지 않는다.
   시스템(폰 설정)의 글자 크기 배율도 곱해 존중한다. 상한 1.8배.
2. 화면마다 크기를 직접 고친다 — 수백 곳이라 실수와 누락이 많아 버렸다.
3. 어르신 화면만 키운다 — 보호자도 큰 글씨가 필요한 경우가 있어 버렸다.

## 설계
- `lib/services/text_size.dart`: 4단계 `[작게 0.85, 보통 1.0, 크게 1.2, 아주 크게 1.45]`, 현재 단계를 `ValueNotifier<int>`로 들고 있고 `SharedPreferences`
  (`app_text_size_index`)에 저장·불러온다. 저장소가 안 되어도 기본(보통)으로 동작한다.
- 옛 채팅 설정(`chat_font_size_index`: 16/19/23/28)이 있고 새 설정이 없으면 같은 순서의 단계로 옮겨 온다(작게→작게 …).
- `main.dart`: 시작할 때 불러오고, `builder`에서 단계 변화를 따라 `TextScaler.linear(단계 배율 × 시스템 배율)`을 적용한다.
- 채팅: 말풍선 글자는 기본 19로 고정하고(전체 배율이 곱해진다), 채팅 설정 창의 글자 크기 고르기는 새 공통 고르기로 바꾼다(번역 언어는 그대로).
- 고르는 곳: 어르신 홈 우상단 `...` 메뉴에 "글자 크기" 추가, 보호자 계정 화면에 "글자 크기" 카드 추가, 채팅 설정 창. 모두 같은 아래 창(`showTextSizeSheet`)을 쓴다.
- 큰 글씨에서 넘치는 화면은 위젯 테스트(좁은 화면 360dp, 배율 1.45)로 찾아 고친다.

## 남긴 판단(내가 정함)
- 단계 수와 이름은 채팅의 기존 4단계를 따랐다. 배율 값(0.85/1.0/1.2/1.45)은 채팅의 16/19/23/28과 비율이 같다.
- 첫 화면(소개 화면)과 로그인 전 화면에도 적용한다(저장된 값이 있으면).
